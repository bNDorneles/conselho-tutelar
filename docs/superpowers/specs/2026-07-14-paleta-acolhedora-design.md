# Design - Paleta Acolhedora

## Objetivo

Ajustar a identidade visual inicial para que o site pareca mais tranquilo, seguro e acolhedor para pessoas que acessam o canal de denuncia anonima.

## Direcao Aprovada

Usar a Opcao A: acolhedora e institucional.

## Sensacao Desejada

- Claro e calmo.
- Seguro sem parecer policialesco.
- Institucional sem parecer burocratico demais.
- Acolhedor para uma pessoa em situacao sensivel.
- Adequado para denuncia envolvendo criancas e adolescentes.

## Paleta

- Fundo principal: off-white quente.
- Cards: branco suave.
- Texto principal: cinza-azulado escuro.
- Primaria: verde/teal sereno para acoes e identidade.
- Secundaria: azul claro para areas informativas.
- Acento: pessego/amarelo suave para destaques discretos.
- Destrutiva: vermelho controlado apenas para erros e alertas.

## Regras Visuais

- Evitar dark mode como experiencia principal neste momento.
- Evitar fundos escuros em secoes publicas de denuncia.
- Evitar contraste agressivo ou cores muito saturadas.
- Usar bordas leves e sombras discretas.
- Manter componentes com raio moderado, sem aparencia excessivamente ludica.

## Criterios De Aceite

- A pagina publica nao deve parecer dark ou pesada.
- A area administrativa deve continuar clara e legivel.
- `npm run lint` deve passar.
- `npm run build` deve passar.
- Verificacao visual em desktop e mobile nao deve indicar overflow horizontal.
